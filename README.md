# એન્જિન ડિસમેન્ટલિંગ લેબ · Engine Dismantling Lab

3D simulator of a 4-cylinder 2.0 L DOHC 16V petrol engine, made for ITI Mechanic Diesel / Motor Vehicle students.
Students take the engine apart part by part, look inside, and watch how it runs.

**Languages:** ગુજરાતી · हिंदी · English

## Features

- **Simulator:** tap any part to see its name and remove it. The order follows the real workshop sequence.
  - Undo, "remove all" and re-assemble.
  - X-ray, cutaway and exploded views.
- **Running engine:** pistons, crank, cams, valves, timing belt and accessory belt move together. Firing order is 1-3-4-2.
  - The gas in each cylinder changes colour by stroke: suction, compression, spark, power, exhaust.
  - Air flows into the intake and black/blue/white smoke comes out of the exhaust.
- **Galleries:** oil galleries and the water jacket in separate colours.
- **Guided demos:**
  - how the 4-stroke engine works
  - dismantling with the tool for each part
  - assembly with torque values
  - optional voice narration
- **Theory** and **MCQ** tabs.
- **Original factory colours** by default; the 🎨 button adds teaching colours.
- **Full screen** on a computer.

## How to use

Open `index.html` in Chrome, Edge or Firefox. An internet connection is needed, because three.js and the fonts load from a CDN.

To publish it as a website, go to **Settings → Pages**, choose **Deploy from a branch → `main` / root**, and save.
